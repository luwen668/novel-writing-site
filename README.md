# ✍️ 文心织网 · 小说写作知识图谱

一个水墨文艺风的小说写作技巧知识图谱：九大维度、五十余个知识点，每个知识点配有名家段落示例与技法拆解、练笔作业，点击节点即可深入阅读。

## 内容覆盖（九大维度）

| 维度 | 知识点 |
|---|---|
| 🏗️ 故事结构 | 总论、三幕结构、英雄之旅、救猫咪节拍表、伏笔与回收、情节反转、开头设计、结尾设计 |
| 👤 人物塑造 | 总论、外貌描写、性格塑造、人物动机、人物弧光、配角设计、反派塑造、群像写作、人物出场 |
| 👁️ 视角叙事 | 总论、第一人称、第三人称限知、全知视角、POV 切换、不可靠叙述、叙事时序 |
| 💬 对话潜台词 | 总论、潜台词、对话节奏、语言个性 |
| 🎨 场景描写 | 总论、环境描写、动作描写、心理描写、五感写作、细节与留白 |
| ⚡ 节奏张力 | 总论、悬念设计、冲突设计、张弛节奏、章末钩子、信息释放 |
| 🖋️ 文风语言 | 总论、比喻的艺术、白描与工笔、句子的节奏、通感与意象 |
| 🎭 类型专项 | 言情、悬疑推理、科幻、玄幻仙侠、武侠、现实主义 |
| 🔁 修改打磨 | 分层修改法、删减原则、读者视角修改 |

## 技术实现

- 纯静态网站（HTML + CSS + 原生 JS），无构建步骤
- [ECharts](https://echarts.apache.org/) 力导向图实现知识图谱可视化
- [GSAP](https://gsap.com/) + ScrollTrigger 实现打字机、滚动渐入、水墨转场
- 水墨文艺设计：宣纸纹理底、朱砂印章、宋体排版、竖排标语
- 部署在 Cloudflare Pages，推送 main 分支自动重新部署

## 本地运行

```bash
python3 -m http.server 8000
# 打开 http://localhost:8000
```

## 如何添加/修改知识点

所有内容都在 `content/content-01.js ~ content-09.js` 中（按维度分文件），每个知识点是一个对象：

```js
window.NODES.push({
  id: "my-topic",           // 唯一标识，用于页面跳转与互链
  name: "知识点名称",
  category: 2,              // 0-8 维度索引，见 data.js 顶部 CATEGORIES
  tagline: "一句话简介",
  summary: "图谱悬停提示",
  content: `<h3>标题</h3><p>详细内容（支持 HTML）</p>`,
  links: ["other-topic"],   // 相关知识点 id 列表（仅限已存在的 id）
});
```

添加后图谱和详情页会自动更新，无需修改其他文件。

> 注意：`content` 是 JS 模板字符串，内部禁止使用 ASCII 双引号和反引号（用中文引号“”代替）。

## 页面样式约定

内容中可直接使用这些样式类：

- 名家示例：`<div class="example-card"><p class="example-quote">引文</p><p class="example-source"><span class="src-seal">书名</span>作者 · 出处</p><p class="example-analysis">技法拆解</p></div>`
- 练笔作业：`<div class="practice-box"><p>练习内容</p></div>`
